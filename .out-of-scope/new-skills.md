# New skill proposals

This repo does not take proposals or contributions for new skills.

Every skill is maintenance surface: it has to stay in step with its docs page, the README, the plugin manifest and the checks. The catalog holds only skills I run on my own work, so I find their failures myself. If a behaviour composes from existing skills, it does not get a new one.

Publishing your own skill is easy: `npx skills@latest init` scaffolds one, and nothing here needs to know about it.

A concrete failure in an existing skill is a different thing, and is judged against [SCOPE.md](../SCOPE.md).
