# 术语锁定表（项目模板）

复制到项目里（例如 `<project>/prose/terms.md`），改写前填好。下列词原样保留，不做同义替换。同一行以第一列为准，改写时发现其他写法就统一过来。

| 统一写法 | 不再使用 | 说明 |
|---|---|---|
| （研究对象代号，如 B公司） | 该公司、企业（指它时） | |
| （核心产品名） | （各种简称） | |
| （角色名） | （同义岗位名） | 与表 X-X 一致 |
| （问题编号或名称） | | 全文措辞一致，不改口径 |
| （分析框架名，如 PEST、SWOT） | | 称"分析框架"，不称"研究方法" |

另外原样保留：引文标记、表号图号、访谈编号、匿名代号。

改写中发现新的需要统一的术语，加到这张表里。项目专属的空词（在本稿反复出现、可换成具体动作的抽象名词）写成下面这种行，用 `prose_check.py --lexicon <本文件>` 追加检查：

抽象：（词1），（词2）
