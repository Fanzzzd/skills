# AI 模式编号表

扫描和评审都用这些编号标注段落。C/L/S/T/F/ST 组来自 WaterPaper 的 AI 模式分类，X 组是长篇中文稿件迭代中补充的。

## 内容 C

| 编号 | 名称 | 特征 |
|---|---|---|
| C01 | 夸大意义 | 标志着、具有深远意义、发挥至关重要的作用 |
| C02 | 模糊归因 | 有学者指出、研究表明、行业普遍认为，没有具体引用 |
| C03 | 提纲式展望 | 结尾机械列出宏大挑战，没有具体内容 |
| C04 | 宣传腔 | 革命性、开创性、全方位、深度赋能 |
| C06 | 肤浅分析结尾 | 句尾加"从而凸显了……""彰显了……" |
| C07 | 通用积极结论 | "为……发展指明了方向""提供了有益借鉴" |

## 语言 L

| 编号 | 名称 | 特征 |
|---|---|---|
| L01 | AI 高频词群 | 此外、至关重要、深入探讨、综上所述，密集出现 |
| L02 | 系动词回避 | 不写"是""有"，改写成"充当了""呈现出" |
| L03 | 否定式对照 | 不是 A 而是 B、不在 A 而在 B、并非 A 而是 B、不仅……更…… |
| L04 | 硬凑三项 | 三个并列形容词或短语，内容撑不起 |
| L05 | 同义轮换 | 策略、举措、路径、方案指同一件事却轮换使用 |
| L06 | 限定叠加 | 可能在一定程度上或许…… |
| L07 | 填充短语 | 值得注意的是、需要指出的是、不可否认 |

## 结构 S

| 编号 | 名称 | 特征 |
|---|---|---|
| S01 | 编号骨架 | 正文用（1）（2）（3）组织论证 |
| S02 | 直线闭环 | 问题→方法→结论一条直线，没有条件、例外、代价 |
| S03 | 模板段落 | 每段都是"主题→解释→例证→总结" |
| S04 | 路标句 | "接下来本章将……""如上表所示""第X节看的是……" |
| S06 | 中文序号排比 | 一是……二是……三是……；首先……其次……最后…… |
| S07 | 自问自答 | "为什么？因为……"连续出现 |
| S08 | 同构数据罗列 | 四项以上数据用同一句式 |
| S09 | 章节过渡模板 | "以上讨论了 X，下面讨论 Y" |
| S10 | 同构问题陈述 | 连续三句以上相同句式陈述不足 |

## 语气 T、格式 F、统计 ST

| 编号 | 名称 | 特征 |
|---|---|---|
| T02 | 宣告式开头 | "随着……的发展"开篇，不直接切题 |
| T03 | 免责腔 | "根据现有资料""就目前可得信息而言"反复出现 |
| F01 | 破折号 | 用 `——` 做插入解释 |
| F02 | 加粗和列表 | 正文加粗、正文列表 |
| ST01 | 可预测词 | 广泛应用、提供新思路、显著提升 |
| ST02 | 句式均匀 | 连续多句长度和结构相近，如反复"通过……从而……" |
| ST03 | 词汇泛化 | 通用词多，缺少本文对象的具体名称、阶段、指标 |

## 补充 X

| 编号 | 名称 | 特征 | 例子 |
|---|---|---|---|
| X01 | 抽象名词堆叠 | 用名词短语掩盖简单动作 | "价值确认接口""资源转化条件" |
| X02 | 防御性声明 | 反复说明没有什么、不代表什么 | "本章未取得……不报告……也不将……解释为……" |
| X03 | 过程泄漏 | 写作过程、资料获取、审稿要求进入正文 | "为补齐营销组合""按审稿要求""为避免口径悬空" |
| X04 | 报告腔主语 | "本文"作主语过密，同一页三次以上 | "本文据此提出""本文认为" |
| X05 | 直译语序 | 长定语、英文式后置 | "一个能够……的……的……" |
| X06 | 审稿回复口吻 | 像在回复审稿意见 | "该指标反映的是""不能理解为""并不意味着" |
| X07 | 无主语建议 | "需加强……""应完善……"没有执行者 | "需加强渠道建设" |
| X08 | 格言式段尾 | 段尾是一句可单独引用的对称句或"代替不了"句 | "统一的品牌代替不了项目分工""越……越……；过……又……" |
| X09 | 口语冒充自然 | 为了"像人"塞进聊天口吻 | "有它的道理""情况就变了""各说各的" |

## 不计为命中

- 有实质内容差异的分类或列举。每项内容不同，删去任何一项都会丢信息。
- 学校或期刊模板规定的结构句和表格引导句。
- 方法小节里一次性的资料边界说明。
- 受访者的直接引语。
